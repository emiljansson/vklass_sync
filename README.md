# Lyssna

Enkel webbapp för att lära dig uttal av de vanligaste engelska orden.

## Funktioner

- **3700+** vanliga engelska ord med svensk översättning
- Uppläsning via webbläsarens **Web Speech API** (engelska)
- Varje ord **repeteras 3 gånger**
- Spela / pausa, föregående / nästa, justera talhastighet
- Framsteg sparas lokalt i webbläsaren

## Starta

```bash
cd frontend
yarn install
yarn start
```

Öppna [http://localhost:3000](http://localhost:3000).

> Uppläsning kräver en modern webbläsare (Chrome, Edge, Safari, Firefox).
> Vissa miljöer blockerar ljud tills du klickar på **Börja öva**.
